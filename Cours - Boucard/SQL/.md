## 12. Plantes de la serre n°3
```sql

FROM PLANTE P

ORDER BY P.nomplante DESC;
```

## 13. Plantes d'Afrique équatoriale et tropicale
```sql
SELECT P.nomplante, R.nomregion
FROM PLANTE P
```

## 14. Plantes de la serre Exoticus (double jointure)
```sql
SELECT P.nomplante
FROM PLANTE P
JOIN EMPLACEMENT E ON P.noplante = E.noplante
JOIN SERRE S ON E.noserre = S.noserre
WHERE S.nomserre = 'Exoticus';
```

```sql
SELECT COUNT(*) AS "Nombre de plantes"
```

## 16. Régions ayant au minimum 2 plantes
```sql
SELECT R.noregion, R.nomregion, COUNT(P.noplante) AS "Nombre de plantes"
FROM REGION R
JOIN PLANTE P ON R.noregion = P.noregion
GROUP BY R.noregion, R.nomregion
HAVING COUNT(P.noplante) >= 2;
```


## 17. Fréquence moyenne pour la serre Georges Bouvet

## 18. Fréquence moyenne pour chaque serre
```sql
SELECT S.noserre, S.nomserre,
       AVG(V.frequence) AS "Fréquence Moyenne"
FROM SERRE S
JOIN VAPORISATION V ON S.noserre = V.noserre
GROUP BY S.noserre, S.nomserre;
```


## 19. Serres dont la fréquence moyenne est supérieure à 13
```sql
SELECT S.nomserre AS "Nom Serre",
       AVG(V.frequence) AS "Fréquence Moyenne"
FROM SERRE S
JOIN VAPORISATION V ON S.noserre = V.noserre
GROUP BY S.noserre, S.nomserre
HAVING AVG(V.frequence) > 13;
```

```sql
SELECT nomplante
```

```sql

GROUP BY P.NoPays, P.NomPays;
```


12. **Prix au kilogramme de chaque article :**
```sql

       CASE
           WHEN descriptif = 'G'
               THEN prixUnitaireHT / (quantite / 1000.0)
           WHEN descriptif = 'P'
               THEN prixUnitaireHT / ((quantite * poidsPiece) / 1000.0)

ORDER BY "Prix au kilogramme" ASC;
```

```sql
FROM PRODUIT;
```

# 9 - Index et vues

1. **Sur quels attributs de PRODUIT est-il pertinent de créer des index ?**
> Les index sont intéressants sur les colonnes utilisées fréquemment pour rechercher, trier ou effectuer des jointures :
> - `reference` : déjà indexée automatiquement puisqu'elle est clé primaire.
> - `designation` : utile pour rechercher un produit par son nom.
> - `descriptif` : utile si les recherches filtrent souvent sur "P" ou "G".
> Il est généralement peu pertinent de créer des index sur des colonnes peu sélectives, comme descriptif si elles ne contiennent que deux valeurs, ou sur des colonnes rarement utilisées dans les recherches.

2. **Créer des index sur noVendeur et noClient dans COMMANDE :**
```sql
CREATE INDEX idx_commande_novendeur
ON COMMANDE(noVendeur);

CREATE INDEX idx_commande_noclient
ON COMMANDE(noClient);
```

- Peut-on ajouter une contrainte UNIQUE ?
> Non, car un même vendeur peut réaliser plusieurs commandes et un même client peut passer plusieurs commandes. Les valeurs de ces colonnes peuvent donc se répéter.

3. **Créer la vue totauxvendeur regroupant les ventes HT par vendeur :**
```sql
CREATE VIEW totauxvendeur AS
SELECT V.noVendeur,
       V.nom,
       COALESCE(SUM(C.totalHT), 0) AS totalHT
FROM VENDEUR V
LEFT JOIN COMMANDE C ON C.noVendeur = V.noVendeur
GROUP BY V.noVendeur, V.nom;
```
> Pour afficher son contenu :
```sql
SELECT *
FROM totauxvendeur;
```

4. **Insérer Durant, Pierre, vendeur numéro 100, avec 2 000 € de ventes dans la vue :**
```sql
INSERT INTO totauxvendeur (noVendeur, nom, totalHT)
VALUES (100, 'Durant, Pierre', 2000);
```
> Cette insertion échoue normalement. La vue contient une jointure et une fonction d'agrégation (SUM), elle n'est donc pas directement modifiable par une insertion classique.
> Il faut insérer les données dans les tables d'origine, notamment VENDEUR et COMMANDE, pour obtenir ce résultat dans la vue.

5. **Créer la vue produitsalapiece contenant uniquement les produits vendus à la pièce :**
```sql
CREATE VIEW produitsalapiece AS
SELECT *
FROM PRODUIT
WHERE descriptif = 'P';
```

6. **Insérer un produit vendu au poids dans la vue :**
```sql
INSERT INTO produitsalapiece (
    reference,
    designation,
    quantite,
    descriptif,
    prixUnitaireHT,
    stock,
    poidsPiece
)
VALUES (
    5000,
    'PALETS BRETONS',
    500,
    'G',
    18.00,
    120,
    0
);
```
> Sans option supplémentaire, cette insertion peut fonctionner et ajouter le produit dans la table PRODUIT, même si "descriptif = 'G'" ne correspond pas au filtre de la vue.
> Pour empêcher cela, il fallait créer la vue avec "WITH CHECK OPTION" :
```sql
CREATE OR REPLACE VIEW produitsalapiece AS
SELECT *
FROM PRODUIT
WHERE descriptif = 'P'
WITH CHECK OPTION;
```
> Avec cette option, PostgreSQL refuse les insertions ou modifications qui ne respectent pas la condition de la vue.

# 10 - Les tablespaces ou espaces logiques

```sql

    noemploye NUMERIC(4),
```
